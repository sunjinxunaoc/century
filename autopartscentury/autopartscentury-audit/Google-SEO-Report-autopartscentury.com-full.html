2. Audit Categories

2.1 Technical SEO

Score: 78/100

What Works

  • 163/163 pages return 200 with perfect canonicals
  • Valid sitemap.xml (163 URLs), /search correctly noindex
  • Zero mixed content, clean URL structure, llms.txt present
  • Good mobile viewport markup

Findings

Soft 404s site-wide Critical

Unknown URLs return HTTP 200 with homepage content; no 404.html emitted in dist; wastes crawl budget and dilutes signals

Recommendation: Emit static 404.html and configure host to return real 404 status; add 301 from non-trailing-slash to trailing-slash URLs

Non-trailing-slash URLs return 200 duplicate High

/about, /search etc. serve duplicate homepage content instead of 301 to /about/

Recommendation: Configure host redirect rules non-slash -> slash

All 163 sitemap lastmod identical Medium

Every URL stamped with build date; lastmod loses meaning for recrawl prioritization

Recommendation: Stamp lastmod from actual content change date in gen-sitemap.mjs

No security/cache headers Medium

vite preview sends no HSTS/CSP/Cache-Control (host-level config)

Recommendation: Configure production host headers: long-cache immutable /assets, security headers

2.2 Content Quality

Score: 74/100

What Works

  • No thin product pages (404-582 words each)
  • No duplicate or missing titles; natural spec-driven copy
  • Clean heading hierarchy on inner pages; 4 strong ~2,200-word news articles

Findings

Near-duplicate sibling product descriptions High

29 groups covering ~60-70 of 148 product pages; e.g. VC-8 cap family identical except color word - risks SERP clustering/filtering of model pages

Recommendation: Add 1-2 differentiating sentences per sibling (vehicle applications, compatibility, packaging)

Homepage renders 3 H1s (hero carousel) High

Each hero slide outputs an H1

Recommendation: Keep first slide H1, demote slides 2-3 to div/p

161/163 titles exceed 60 chars Medium

Model-first titles are good but truncate in SERP

Recommendation: Trim suffix patterns to keep core model + category within 60 chars where possible

News articles lack author + internal links to products Medium

No E-E-A-T author signal, articles don't link to catalog pages

Recommendation: Add author/date byline and in-article links to relevant product/category pages

About page has no certifications Medium

No ISO/IATF/QA content anywhere on site

Recommendation: Add certifications + factory capability content to About

2.4 Schema / Structured Data

Score: 38/100

What Works

  • Organization schema on homepage and Product schema on 148 product pages are valid JSON with absolute URLs
  • No parse errors, no placeholder values

Findings

No BreadcrumbList anywhere High

Visual breadcrumbs render on all 163 pages but emit no schema

Recommendation: Emit BreadcrumbList JSON-LD from BreadcrumbNav.vue - one component change, SERP-visible result

Product schema ineligible for rich results High

Missing offers/review/aggregateRating and sku/mpn

Recommendation: Add mpn (model number), brand, and Offer (businessFunction/priceSpecification appropriate for B2B RFQ) to Product JSON-LD

14/163 pages have zero JSON-LD High

All category, news, about, contact pages have no structured data

Recommendation: Add CollectionPage to subcategories, Article/NewsArticle to news (headline, image, datePublished, author), ContactPage/AboutPage

FAQ sections without FAQPage markup Medium

Visible FAQs on home + 6 categories + 4 news pages; Google FAQ rich results deprecated for most sites but still valuable for AI surfaces

Recommendation: Emit FAQPage JSON-LD from FaqSection.vue

2.5 Performance (CWV)

Score: 72/100

What Works

  • Route-level code splitting, 98.7% WebP images, zero webfonts, zero third-party scripts
  • Broad lazy loading, prerendered SSG HTML

Findings

696KB logo PNG displayed at 40x40 Critical

1024x1024 PNG loaded eagerly in header on all 163 pages - largest single byte cost on the site

Recommendation: Resize to ~160px WebP (~5KB)

Hero carousel images eager, no fetchpriority High

All 3 hero banners (1920x640 webp) load eagerly; LCP image competes with ~930KB eager imagery

Recommendation: fetchpriority=high on first slide only, lazy-load slides 2-3, add preload

298KB products.js inside main bundle High

Full catalog hoisted into 356KB app bundle via SiteHeader/SearchBar imports - downloaded on every page

Recommendation: Split search index into a lazily loaded chunk (dynamic import on search focus)

No srcset / width+height on content images Medium

Responsive sizing and CLS reserves missing

Recommendation: Add width/height attrs; generate srcset variants for product images
